# 🤖 AI Chat Box - Next-Gen Intelligence

A modern, responsive, and feature-rich AI Chat web interface crafted with vanilla web technologies, ambient glassmorphism visuals, and real-time interactive capabilities.

**Developer:** Pawan Solunke

---

## ✨ Features

- 💎 **Modern Glassmorphic UI**: Ambient glow refractions, dark/light theme switching, and smooth micro-animations.
- ⚡ **Multi-Engine AI Integration**: Seamless connection to live AI engines with custom model settings and parameters.
- 🌐 **Web Search & Knowledge Retrieval**: Built-in support for live web searches and grounded answers.
- 📁 **File & Document Drag-and-Drop**: Upload and process images, PDFs, text, and documents directly in chat.
- 📷 **Live Camera Module**: Interactive snapshot and live vision integration.
- 💬 **Conversation Management**: Chat history drawer, session persistence, export, and quick-clear controls.
- 📱 **Fully Responsive**: Optimized for desktop, tablet, and mobile displays.

## 🚀 Quick Start

### Prerequisites
- Python 3.x (or any static local web server)

### Running Locally

1. Clone or download the repository:
   ```bash
   git clone <repository-url>
   cd "Ai chat box"
   ```

2. Run the local server:
   - On **Windows**: Double-click [`run.bat`](run.bat) or run:
     ```powershell
     python -m http.server 5500
     ```
   - Open your browser at [http://localhost:5500](http://localhost:5500).
